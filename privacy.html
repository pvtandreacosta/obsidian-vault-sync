Come vengono trattati i dati

Questa informativa descrive il client OAuth personale usato con rclone per sincronizzare file Obsidian e Google Drive. Non è un servizio web che riceve le note.

Dati e autorizzazioni

Quando autorizzato, rclone può accedere ai file e ai metadati dell’account Google Drive. L’ambito drive richiesto dal client consente di visualizzare e gestire tutti i file di Drive. La configurazione rclone prevista indicherà la cartella Obsidian/Vault come radice del remote, ma questa impostazione limita il normale percorso operativo di rclone, non i permessi OAuth concessi a Google.

I file interessati possono includere note Markdown, allegati, nomi e metadati necessari alla sincronizzazione. Quando l’utente autorizza rclone, il token OAuth viene conservato localmente nella configurazione rclone sul computer dell’utente; chiunque possa leggere quel file potrebbe usare il token secondo i permessi concessi.

Uso e trasferimento

rclone viene eseguito sul computer dell’utente e trasferisce i file direttamente tra il vault locale e Google Drive. Il gestore di questo progetto non riceve, ospita o vende il contenuto dei file e non usa un proprio server per elaborarlo. Google tratta i dati archiviati in Drive secondo le proprie condizioni e informative.

Il client OAuth non invia automaticamente note a servizi di intelligenza artificiale. Se l’utente sceglie di condividere note con GPT, Codex, Claude Code o altri servizi, il trattamento da parte di quei fornitori è regolato dalle rispettive informative.

Conservazione e revoca

Le copie locali e quelle in Drive restano finché l’utente non le elimina. L’utente può revocare l’accesso dalle impostazioni di sicurezza del proprio account Google e rimuovere la configurazione rclone locale. La revoca non cancella automaticamente i file già presenti in Drive o sul computer.

Visite al sito informativo

Le pagine sono statiche e non includono moduli, strumenti di analisi o cookie propri. Se ospitate con GitHub Pages, GitHub registra e conserva l’indirizzo IP dei visitatori per motivi di sicurezza; si applica anche la informativa privacy di GitHub.

Contatti

Per domande sull’autorizzazione o su questa informativa, usa l’indirizzo di supporto mostrato nella schermata di consenso Google dell’app.

Nota sull’ambito: Google classifica drive come ambito ad accesso esteso. Prima di autorizzare il client, verifica che il nome dell’app e l’account Google nella schermata siano quelli attesi.
